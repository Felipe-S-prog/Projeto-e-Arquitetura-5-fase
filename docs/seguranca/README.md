# Segurança da informação — SGP

> **Simulação acadêmica.** O SGP não tem certificação. Estes documentos mostram o que a ABNT NBR ISO/IEC 27001 exigiria se o sistema fosse operado oficialmente, aplicando as normas da família ISO 27000 (27001, 27002, 27005, 27017, 27018 e 27701) e a LGPD ao sistema real.
